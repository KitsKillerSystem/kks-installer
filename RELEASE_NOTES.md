# KKS 1.0.0

First public release. Promoted from KKS 1.0.0-rc.1 after user-confirmed final in-game QA.

The game payload is unchanged from the approved candidate. The installer identifies itself as 1.0.0, retains Install, Repair, Restore Vanilla and interrupted-operation recovery, and requires no xTranslator. Supports Steam English Slasher build 25258219.

Keep the `.kks-installer-1.0.0` restoration folder in the game directory. A future installer that carries 1.0.0 compatibility support can use those verified backups and receipts without the old executable. The restoration contract is included; no new upgrade feature or backup format was introduced for this release. Unknown or newer Bethesda files must never be overwritten using old backups.
